# 판교 더 서바이벌: 바이브 코딩 네크로맨서의 강림

B급 감성 개발자 ARPG 프로토타입. 원작 기획: `zari-harmony-room` 이슈 #667 (로어 01~30).

> "손코딩? 물리타격은 젊은 놈들이나 하는 거고." — 덕산

## 실행

빌드 불필요. `index.html`을 브라우저로 열면 바로 실행됩니다.

```bash
# 또는 간단한 로컬 서버
npx serve .
```
