## 왜 기계로 강제하나

이 게임은 **반드리프트·반환각 프로토콜** 위에서 만들어졌습니다.

```bash
# 훅 설치 (클론 후 1회)
bash tools/install-hooks.sh
```

가드(`tools/guard.mjs`)는 매 커밋마다 fail-closed로 검문합니다:
- JS 문법 · JSON 유효성 · 캔버스 960×600 불변식
- 척추 함수 존재 (update/render/resetGame/castSkill/damageEnemy/drawUnit)
- 비밀키·토큰 스캔 · **코드 건강(파일 줄수 예산·고아 파일)**
- 가드 자신도 자기를 검문한다

> "기억이 아니라 도구를 고쳐라. 기계에 보증을 박아라."
> — [PROTOCOL.md](PROTOCOL.md) P1~P8

## 세션 실황 — 이 채팅이 게임이 된다

`docs/session-stream.json` — 이 게임을 만든 실제 대화 66엔트리가 박제돼 있습니다.

게임 안에서 **K키**를 누르면 이 파일의 최신본을 GitHub에서 fetch해 우측 패널에 흘려줍니다. 게임과 제작 과정이 한 화면에 공존합니다.

## 기여 — 당신이 PR을 날리면 세계가 바뀝니다

이 레포는 **Asymmetric Repo Warfare**([이슈 #5](../../issues/5))의 준비 중인 전장입니다.

```
당신이 할 수 있는 것:
  - 버그 발견 → 이슈 발행 (현상금 시스템 개발 중 — 이슈 #16)
  - 몬스터 추가 → PR (git blame에 당신 이름이 박힌다 — 이슈 #12)
  - 던전 설계 → TODO 주석 추가 = 새 던전 생성 (이슈 #9)
  - AI 에이전트로 그리핑 도전 (이슈 #5, #18)
```

가드를 통과해야 merge됩니다. AI도 예외 없음.
