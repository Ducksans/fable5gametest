# 판교 더 서바이벌: 바이브 코딩 네크로맨서의 강림

B급 감성 개발자 ARPG 프로토타입. 원작 기획: `zari-harmony-room` 이슈 #667 (로어 01~30).

> "손코딩? 물리타격은 젊은 놈들이나 하는 거고." — 덕산

## 실행

빌드 불필요. `index.html`을 브라우저로 열면 바로 실행됩니다.

```bash
# 또는 간단한 로컬 서버
npx serve .
```

## 조작 (디아블로식 쿼터뷰 — 로어 17 정본 키 배치)

| 입력 | 동작 |
|---|---|
| 좌클릭 (홀드 가능) | 이동 · 몬스터 클릭 = "저기 쳐!" 소환수 지휘 |
| 우클릭 | 키보드 폭발 — 커서 위치 시체(해결된 버그)를 터트려 키캡 파편 광역딜 |
| Q | CG 스켈레톤 워리어 소환 — 백엔드 물리딜러 |
| W | GG 스켈레톤 메이지 소환 — break 드릴 원거리 |
| E | AG 스톤 골렘 소환 — 탱커, 어그로 담당 |
| Space | 서브에이전트 웨이브 소환 (동시 캡 16 — 웨이브로 굴려라) |
| R | 궁극기: PASS 선언 — 시야 내 일괄 소탕 (보스는 저항) |
| 방향키 | 보조 이동 |

## 게임 구조

아이소메트릭 오픈 필드(2200×2200) ACT 순환제. 판교역 3번 출구(스폰 광장)에서 시작해 길바닥 몹팩을 사냥하며 남동쪽 **레거시 유적지**의 보스 아레나로 진행한다. 보스 격파 시 다음 ACT — 몬스터가 강해지고 레벨·커밋토큰은 유지된다.

- **원본**: [docs/session-stream.json](docs/session-stream.json) — 의장과 3금강(CG·Fable5)의 대화가 턴 단위로 박제됨.
- **준 실시간**: 매 턴(=메시지 한 번) 이 파일에 새 장면이 추가되어 GitHub에 커밋됩니다. 게임은 K패널을 열 때마다 이 파일의 **최신본을 fetch**해 보여줍니다 — 로컬 서버로 열면 새로고침 없이도 흘러듭니다.
- 세션 자체가 게임의 콘텐츠가 되는 구조. "내가 앉은 자리가 곧 판교"이듯, 지금 이 대화가 곧 게임입니다.

## 원작 로어 — 3금강이 쓴 원본

이 게임의 설계도 전체(이슈 #667 본문 + 로어 01~30 댓글)는 [docs/issue_667_full.md](docs/issue_667_full.md)에 **원본 그대로** 박제되어 있습니다.

이 문서 자체가 하모니룸 **3금강(AG·CG·GG)**이 브로커를 통해 이슈 #667에 직접 작성한 원본입니다 — 안티그래비티가 통째로 내려받은 파일을 한 글자도 고치지 않고(sha256 `3b251e9e…`) 그대로 올렸습니다. 각 댓글 말미의 `broker-receipt · agent=AG/CG/GG` 서명이 그 증거입니다.

**키 배치 정본 복원:** v2에서 마우스 이동(디아블로식)으로 전환하며 로어 17 정본 키(Q=CG, W=GG, E=AG)를 복원했습니다. 로어 17의 "R=소환수 지휘"는 좌클릭 몬스터 지휘("저기 쳐!")로 옮겼고, R키는 로어 11 정본대로 궁극기 PASS 선언입니다.

## 스킬트리 · 아이템 (v4 — POE 스타일)

**스킬트리 (T키)** — 레벨업마다 포인트 +1, 노드 클릭 분배, 선행 노드 조건:
- **소환계** (로어 06): 군단장 오라(이속/공속) → 군단 증폭 / 뼈다귀 보강 → 팬아웃 소환(웨이브 6기) / 1인2역 환영술(환영 골렘, "어? 너 둘이야?") → 삼금강 각성(3금강 생존 시 딜 +30%)
- **레거시 시학 / 시체폭발** (로어 07): 폭발 증폭 → 반경 / manifest 산탄(+8파편) → **연쇄폭발(랭크=연쇄 상한, max3 fail-closed, 감쇠 0.7배)** / 타건 장판(DPS존) → 청축 각성(크리 30%)
- **야인의 근성**: 산전수전(HP) → 카페인 혈관 / 자전거 7년 → 부동산 화술(토큰) / PASS 숙련

**아이템 (I키)** — POE식 등급·어픽스·장비 6슬롯(무기/상의/머리/목걸이/반지/부적):
- 등급: 일반(흰) → 매직(파랑, 1~2옵) → 레어(노랑, 3~4옵 + 접두어) → **유니크(주황, 로어 명품)**
- 유니크: 기계식 키보드 · 휘발된 라이브 서명키("파일 부재 ≠ 휘발") · 80라운드 회고의 반지(소환 마나 -20%) · 터틀넥 오브 판교
- 드랍: 잡몹 7% · 엘리트 60%(+유니크 8%) · 보스 레어 2개 확정(+유니크 50%). 바닥 라벨 색 = 등급, 밟으면 획득
- 어픽스 풀: 소환수 데미지/HP, 폭발 데미지, 최대 HP, 아메리카노 재생, 이속, 커밋토큰/PASS 게이지 획득
